# rungsapp.com

One-screen landing page for Rungs, served by GitHub Pages from `main` at https://rungsapp.com.

- `index.html` is the whole site. The laurel mark and wordmark are inlined from the brand kit SVGs.
- To show the App Store button at launch, set `data-href` on `#cta` in `index.html` to the App Store URL.
- `CNAME` holds the custom domain. Don't delete it.
